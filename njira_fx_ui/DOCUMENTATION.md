# Njira fx Frontend – Code Documentation

## 🗂 Project Structure

```
/pages         → Next.js route files (e.g. /index.tsx, /about.tsx)
/components    → Reusable UI components like Button, Navbar, etc.
/utils         → Utility functions (e.g. calculateTax)
/styles        → Global CSS or Tailwind config
/types         → TypeScript type declarations
/public        → Static assets (images, icons, etc.)
/docs          → Auto-generated documentation files
.storybook     → Storybook configuration for UI component testing
.next          → Next.js build output directory
```

### Additional Notes:

- **`/pages`**: Each file corresponds to a route in the application. For example, `index.tsx` maps to `/`.
- **`/components`**: Contains modular and reusable UI elements to maintain consistency across the app.
- **`/utils`**: Houses helper functions to simplify complex logic.
- **`/styles`**: Includes global styles and Tailwind CSS configurations.
- **`/types`**: Centralized TypeScript type definitions for better type safety.
- **`/public`**: Stores static assets like images and icons that are directly accessible.
- **`/docs`**: Contains auto-generated documentation files for the project.
- **`.storybook`**: Configuration files for Storybook, used for testing and showcasing UI components.
- **`.next`**: Build output directory generated by Next.js.

## 📌 Notable Files

### `src/utils/calculateTax.ts`

- **Description**: Calculates tax based on income.
- **Params**: `income: number`
- **Returns**: `number` – The calculated tax.

### `src/components/Button.tsx`

- **Description**: Reusable button component.
- **Props**:
  - `label: string` – Text inside the button
  - `onClick: () => void` – Click handler function

### `pages/index.tsx`

- **Description**: Homepage of the app.
- **Functionality**: Fetches and displays main dashboard data.

### `.storybook/main.ts`

- **Description**: Configuration file for Storybook.
- **Purpose**: Defines how components are loaded and displayed in Storybook.

## 💡 How to Run the Project

To set up and run the project locally:

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm run dev
```

### Build for Production:

```bash
pnpm run build
```

### Preview Production Build:

```bash
pnpm run start
```

## ✅ Best Practices

- **Code Quality**:

  - Keep functions small and typed.
  - Use meaningful file and function names.
  - Group related components together for better organization.
- **Styling**:

  - Leverage Tailwind CSS for consistent and responsive designs.
  - Avoid inline styles unless necessary.
- **State Management**:

  - Use Zustand or Context API for lightweight state management.
  - Opt for Redux if the app requires complex state handling.
